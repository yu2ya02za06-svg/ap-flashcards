# 応用情報 一問一答（PWA）

応用情報技術者試験（午前）の頻出テーマを、赤シート式の一問一答で覚える暗記カードです。
ホーム画面に追加でき、電波がなくても使えます。学習の記録はその端末のブラウザ内に保存されます。

- カードは過去問の転載ではなく、直近の午前試験で繰り返し問われているテーマをもとに作成した一問一答です（2026年9月時点）。
- 間隔反復：「覚えた」を押すたびに次の出題が 1→3→7→14→30日後 と延びます。「まだ」はその日のうちにもう一度出ます。
- 3回以上続けて覚えたカードを「定着」として数えます。

## ファイル
- `index.html` アプリ本体
- `cards.js` カードのデータ（`window.AP_CARDS`）
- `manifest.webmanifest` / `sw.js` / `icon-*.png` PWA用

カードを直したら `cards.js` を更新してください（ネット接続時に自動で反映されます）。
